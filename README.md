An entry for the [One-Line Laugh Sprint bounty on make.fun](https://make.fun/bounty/u-daring-gecko-25-one-line-laugh-sprint-cda708b2).

## What it does

`main.py` (Python 3.13, standard library only) writes a single original
one-line joke about everyday life to `/output/entry.txt`:

> I meal-prep on Sundays so that on Wednesdays I can throw away five identical containers of regret.

The output directory can be overridden with the `MAKEFUN_OUTPUT_DIR`
environment variable; it defaults to `/output`.

## Run

```sh
python3 main.py
```
